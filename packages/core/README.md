# @omtre/core

Core channel and task domain primitives for omtre. The CLI bundles this package,
so installing `omtre` does not require a separate install.

Use it directly only when you are building a Node service or integration that
needs the same task, channel, and memory primitives as the CLI.

```bash
npm install @omtre/core
```

See the [omtre repository](https://github.com/ScoFan-official/omtre) for the
workflow, CLI, and documentation. Licensed under AGPL-3.0; see `LICENSE` and
`NOTICE` in the repository.
